# English0.1 (E01)

**Word small. Meaning big. Brain free.**

English0.1 (E01) is a minimal communication system built from English words for games and online chat.

It is not a replacement for English.

Its goal is simple: communicate quickly with a small number of words and very little grammar.

## Quick Example

```text
enemy north
run
wait
team all attack

enemy dead
we win
life good
```

## Basic Rules

- Keep sentences short.
- One line means one message.
- Put the most important word first when useful.
- Use `?` for questions.
- Use `!` for strong commands.
- Use `no` for negatives.
- Add `s` for plurals when needed.
- Numbers may always be used.
- Word order is flexible when the meaning is clear.

Examples:

```text
enemy here?
3 enemies
danger north
no run
team all attack!
```

## Vocabulary System

English0.1 currently uses 128 core words:

- Core Vocabulary: 64 words
- Additional Vocabulary: 64 words
- Total: 128 words

English words outside the list may still be used when needed.

## Numbers

Numbers are universal and do not count toward the 128-word limit.

```text
1 enemy
3 team
10 apple
```

## Repeat Rule

Repeat a word to make its meaning stronger.

```text
big big = very big
danger danger = very dangerous
run run = run now
```

## Join Rule

Combine words to create a larger meaning.

```text
enemy house = enemy base
team help = support
danger north = the north is dangerous
target enemy = attack this enemy
```

## Grammar Summary

English0.1 has no complex grammar.

Use short words, flexible order, repetition, and combination to make the meaning clear.

```text
enemy north
team follow
attack now

old man give apple
man very happy
```

## Version Rule

English0.1 versions move closer to English, but never become English.

Examples:

```text
0.11
0.12
0.13
...
0.19
0.191
0.192
```

Version `0.2` is forbidden.

## Respect for English

English0.1 is based on English words and simple grammar.

English is a powerful and beautiful language used around the world. English0.1 is only a small tool for fast and simple communication in games and online chat.

If English0.1 helps someone become interested in learning English, that would make us very happy.
