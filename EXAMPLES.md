# English0.1 (E01) Examples

This file shows how English0.1 can be used in games and online chat.

English0.1 has no single perfect sentence for every situation. The goal is fast, simple, clear communication.

Normal English meanings are shown after `=`.

---

## 15. Flexible Word Order

English0.1 word order is flexible when the meaning is clear.

```text
enemy north
north enemy
```

Both may mean:

```text
an enemy is north
```

But important information should usually come first.

```text
danger north
```

This emphasizes danger.

```text
north danger
```

This emphasizes the north side.

## 16. One-Line Messages

English0.1 works best when each line contains one message.

```text
enemy north
3 enemies
team wait
attack later
```

This is clearer than one long sentence.

## 21. Strict E01 and Open E01

English0.1 can be used in two ways.

### Strict E01

Use only the 128 core words and numbers.

```text
enemy north
team wait
attack later
```

### Open E01

Use the core system, but add normal English words when needed.

```text
door locked
need key
boss second floor
```

The core words keep the message simple. Extra words add necessary detail.

## 22. Meaning Before Grammar

English0.1 does not require perfect English grammar.

```text
old man give apple
```

Possible meaning:

```text
the old man gives an apple
```

```text
team need heal
```

Possible meaning:

```text
the team needs healing
```

```text
enemy no see
```

Possible meaning:

```text
the enemy does not see us
```

The goal is not perfect grammar.

The goal is clear communication.
