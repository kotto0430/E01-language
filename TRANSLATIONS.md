# English0.1 Translation Guide

English0.1 is intended for people who may not feel confident reading or writing English. Its documentation should therefore be available in the reader's own language whenever possible.

## Translation Principle

Translate the explanation, not the language system itself.

Keep official E01 words, sample E01 messages, abbreviations, filenames, version numbers, and code blocks in their original form unless a short local-language meaning is added beside them.

Example:

```text
enemy north = 北に敵
```

Do not replace the E01 message itself with a translated command, because users must still learn what to type in an international game chat.

## Writing Style

Translations should:

- use familiar everyday language
- avoid difficult grammar terminology when possible
- explain ideas naturally rather than translating word for word
- preserve the welcoming and low-pressure tone
- make clear that imperfect grammar is acceptable
- preserve the distinction between Strict E01, Universal Game Terms, and Open Vocabulary

A beginner should not need advanced English knowledge to understand the manual.

## Source of Truth

The English `README.md` is the current source document for project structure and official rules.

Vocabulary lists and E01 examples must match the official repository files. Translators may improve local-language explanations, but should not silently change the E01 specification.

When the English source changes, translations should be reviewed for the same change.

## File Names

Use language-tagged README files in the repository root:

```text
README.md       English
README.ja.md    日本語
README.zh-CN.md 简体中文
README.zh-TW.md 繁體中文
README.es.md    Español
README.pt-BR.md Português do Brasil
README.fr.md    Français
README.de.md    Deutsch
README.ko.md    한국어
```

More languages may be added freely.

## Suggested Priority

Initial priority is based on likely accessibility and large online gaming communities:

1. Japanese
2. Simplified Chinese
3. Spanish
4. Brazilian Portuguese
5. Korean
6. Traditional Chinese
7. French
8. German

This order is practical, not a statement that one language is more important than another.

## Translation Credit

Translators may add their name or handle under a translation credit section.

Example:

```text
Japanese translation: kotto & Yomi
```

The original project credit and repository link must remain visible.

## Community Translations

Community translations and corrections are welcome.

A translation does not need to copy the English sentence structure exactly. Clear local-language teaching is more important than literal translation, as long as the official E01 rules and examples are represented accurately.
